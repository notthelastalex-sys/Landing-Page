# Landing Page Script Website

A modern responsive frontend website built using HTML and CSS.  
This project includes a stylish landing page layout with navigation, hero section, services, about section, and contact form.

---

## Features

- Responsive modern layout
- Clean navigation bar
- Hero section with image
- About section
- Service cards
- Contact form UI
- Mobile-friendly design
- Smooth hover animations
- Dark modern color palette

---

## Technologies Used

- HTML5
- CSS3
